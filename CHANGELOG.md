# Changelog

All notable changes to `@cairncms/directus-extension-formatter` are documented in this file. Releases are listed in reverse chronological order. Versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-26

- Initial release: a Directus Flow operation with 20 transforms for text, phone numbers, numbers, dates, locale-aware text, and lookups. Format a single value or apply ordered rules to fields.
